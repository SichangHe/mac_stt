# test audio

`librispeech-dev-clean-240s.wav` concatenates LibriSpeech dev-clean utterances
(speaker 1272, chapters 128104, 135031, 141231) separated by 0.8 s of silence.
`librispeech-dev-clean-240s.tsv` lists each utterance with its start, end, and reference text.
Source: https://huggingface.co/datasets/hf-internal-testing/librispeech_asr_dummy (a copy of LibriSpeech).
LibriSpeech (Panayotov et al., 2015) is licensed CC BY 4.0.
